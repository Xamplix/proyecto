# ⚡ Inicio Rápido - 3 Pasos

## 📌 Paso 1: Activar GitHub Pages (2 minutos)

1. Ve a: https://github.com/Xamplix/proyecto/settings/pages
2. En **Source** → selecciona `main` branch
3. Click **Save**
4. ✅ Tu sitio estará en: **https://xamplix.github.io/proyecto/**

## 🔑 Paso 2: Crear Token de GitHub (3 minutos)

1. Ve a: https://github.com/settings/tokens
2. Click **"Generate new token (classic)"**
3. Nombre: `MALLA 2025G`
4. Marca SOLO: ✅ **repo**
5. Click **Generate token**
6. ⚠️ **COPIA EL TOKEN** (solo se muestra una vez)

## 🚀 Paso 3: Configurar y Usar (1 minuto)

1. Ve a: https://xamplix.github.io/proyecto/upload.html
2. Pega tu token cuando te lo pida
3. ¡Listo! Ahora puedes subir archivos

---

## 📤 Migrar desde SharePoint

1. Descarga archivos de SharePoint
2. Ve a: https://xamplix.github.io/proyecto/upload.html
3. Arrastra y suelta los archivos
4. Click "Subir archivos a GitHub"
5. ✅ Archivos guardados en GitHub

## ❓ Problemas Comunes

**"401 Bad credentials"**
→ Token inválido, genera uno nuevo

**"403 Forbidden"**
→ Marca el permiso **repo** al crear el token

**No aparece el modal de token**
→ Presiona F12, escribe: `CONFIG.setToken("tu-token")`
