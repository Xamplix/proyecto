Representation Learning

Como cambio la jerarquia de conceptos tras el arreglo

Sin Regularizacion

  • Memoriza el ruido de cada muestra
  • Las features internas no son transferibles a datos nuevos
  • No aprende conceptos generales (bordes, texturas, formas)
  • Cada neurona se sobreactiva para casos puntuales

Con Regularizacion

  • Captura patrones reales: distribuciones y correlaciones
  • Features compartidas entre muestras similares
  • Capas intermedias actuan como detectores de patrones
  • Jerarquia: features simples → features complejas
La regularizacion fuerza a la red a buscar patrones compartidos en vez de memorizar caso por caso.
